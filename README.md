 

# Site para estúdios de ioga

##  O projeto consiste na construção de uma landing page responsiva a partir de um template gratuito do Figma, implementando boas práticas de componentização, responsividade e organização de código.

---

## Tecnologias utilizadas:

- **React.jsc**  
- **Next.js**  
- **Tailwind CSS**

---

##  Objetivos:

- Transformar um design do **Figma** em código fiel ao layout  
- Criar **componentes reutilizáveis**  
- Aplicar **responsividade** (mobile-first)  
- Trabalhar com **boas práticas de UI e UX**  
- Simular um **projeto real de front-end**
